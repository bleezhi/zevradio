# zevRadio\n\nA local web-controlled radio automation prototype for the Zev network.\n\n## Features\n\n- Web control panel\n- Add/remove music, ads, promos, idents and sweepers directories\n- Recursive audio-library scanning\n- ON AIR / STOP controls\n- Now-playing state\n- JSON API\n- Config file\n- Prepared audio folders for news and weather\n- Local continuous FFmpeg audio stream at `/radio`\n- Simple music/ident/ad/sweeper test rotation\n\n## Quick start\n\n### Windows\n\n```bat\npy -m venv .venv\n.venv\Scripts\activate\npip install -r requirements.txt\npy zevRadio.py\n```\n\nYou also need **FFmpeg installed and available as `ffmpeg.exe` on PATH**.\n\nOpen:\n\n- Control panel: http://127.0.0.1:8080\n- Audio stream: http://127.0.0.1:8080/radio\n\nStart the station from the control panel, then open `/radio` in a player that supports live MP3 HTTP streams (VLC is a good test).\n\nPut audio files into the folders under `audio/`, or add additional directories from the web panel.\n\n## Local testing\n\nThe first streaming backend is deliberately local-only.\n\nWhen ON AIR, `/radio` starts FFmpeg and continuously loops a small test rotation:\n\n1. Music\n2. Ident\n3. Music\n4. Ad\n5. Music\n6. Sweeper (or promo)\n7. Ad\n8. Repeat\n\nThis lets you test the actual audio path before connecting zevRadio to an external simulator or transmitter service.\n\n## Current status\n\nThe control panel, library management, and first FFmpeg streaming backend are implemented. The scheduler is intentionally simple for now; more advanced scheduling, metadata, news/weather insertion, and gapless programming can be added next.\n\n## Suggested station content\n\nUse internal Zev promos instead of real commercial advertising:\n\n- "You're listening to zevRadio."\n- ZevTV cross-promos\n- ZevOS / zevMobile promos\n- station idents\n- sweepers\n- weather/news information spots\n- special-event promos
